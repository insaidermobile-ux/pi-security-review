# Security policy

## Supported versions

Security fixes are provided for the latest 0.x release only. Please upgrade to the latest release before reporting an issue.

## Reporting a vulnerability

Report vulnerabilities in this extension privately through [GitHub private vulnerability reporting](https://github.com/insaidermobile-ux/pi-security-review/security/advisories/new) (Security → Advisories → Report a vulnerability).

Include the affected package and pi versions, steps to reproduce, expected and actual behavior, and potential impact. Remove credentials, private source code, and other sensitive content from logs or examples. Do not open a public issue or pull request with vulnerability details before coordinated disclosure.

We will use the private advisory to discuss reproduction, fixes, and disclosure with you. This policy covers the extension itself, not vulnerabilities it finds in projects you audit.
