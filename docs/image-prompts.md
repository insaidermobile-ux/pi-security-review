## Cover

Use case: ads-marketing
Asset type: striking English hero infographic / gallery thumbnail for pi.dev, GitHub and npm.
Project: pi-security-review, an adversarial multi-agent static security review extension for pi.
Create an exceptionally striking professional developer-tool cover, landscape 3:2, very strong thumbnail readability. Dark near-black navy background. A huge vivid coral-red angular vulnerability glyph / cracked code shield floats in the center, held between two opposing abstract agent entities: cyan scanner on left, amber cross-examination prism on right. Sharp directional light beams converge on the same suspected flaw. Elegant technical editorial illustration, high contrast, sophisticated sparse composition, no generic stock padlock, no humanoid robots. The visual should immediately communicate that one agent finds a bug and a second tests the claim.
Text hierarchy: upper left modest but clearly legible "pi-security-review".
Very large bold white headline across upper half, exactly:
"One agent finds it."
"Another challenges it."
Below main graphic, three short labels in a clean horizontal pipeline:
"HUNT" → "CHALLENGE" → "REPORT"
Tiny but legible footer: "/security-review [full]"
Small secondary text: "Adversarial security review for pi"
Constraints: only these English text elements, exact spelling. Huge headline, generous margins, crisp large glyphs, dramatic coral/cyan focal point that grabs attention at thumbnail size. No fake numerical claims, no security guarantees, no watermark. Polished technical infographic cover, not a screenshot.

## Workflow

Use case: infographic-diagram
Asset type: English project infographic for GitHub README and npm package README.
Create a polished, exceptionally legible landscape infographic for an open source developer tool. Dark navy background, restrained cyan and amber accents, crisp typography, subtle grid, flat vector-like diagrams. Wide 3:2 composition, generous padding. No decorative gibberish.
Exact title: "pi-security-review"
Subtitle: "Adversarial security review for pi"
Main workflow, clear arrows left to right in six numbered compact steps:
"01 Scope" / "Diff or whole project"
"02 Profile" / "Map trust boundaries"
"03 Hunt" / "Parallel vulnerability discovery"
"04 Triage" / "Group by root cause"
"05 Verify" / "Affirmer → Challenger"
"06 Report" / "Persistent findings + Markdown"
Make Verify the central visual highlight in a larger middle-lower panel: two abstract agent nodes, "Affirmer" with "Build the attack path" and "Challenger" with "Try to refute it", connected by a directional arrow.
Three small outcome chips: "Vulnerability", "Risk", "Refuted".
Bottom benefits in three neatly aligned compact columns: "Read-only agents" / "Project-confined inspection"; "Persistent findings" / "Deduplicate across runs"; "Per-role models" / "Choose models for each role".
Footer command in monospace: "/security-review [full]"
Small footer note: "Static analysis • Human judgment required"
Constraints: render all copy verbatim in English. No fabricated metrics, no claim of guaranteed security, no third-party logos, no watermark. Hierarchy and readable text matter more than decoration.
